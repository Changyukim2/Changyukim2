## 🚀 Projects

### 1. iM뱅크 중소기업 세분화 프로젝트
기존 안정성 중심 기업등급을 보완하기 위해  
**활동성(FAI)** 과 **수익성(FPI)** 을 결합한 중소기업 세분화 모델을 설계한 프로젝트입니다.

- 중소기업 고객을 4개 세그먼트로 분류
- 비모수 통계검정 기반 가설 검증 수행
- 숨은 우량 고객군 및 잠재 우량고객 발굴

### 2. Bank Customer Churn Prediction
은행 고객 데이터를 기반으로  
고객 이탈 여부를 예측하고 주요 영향 변수를 분석한 머신러닝 프로젝트입니다.

- 데이터 전처리 및 EDA 수행
- Feature Selection 및 모델 비교
- SHAP 기반 변수 해석 진행

### 3. 낙상 감지 시스템 프로젝트
실시간 낙상 감지를 목표로  
포즈 추정, 딥러닝 모델, 웹 연동을 결합한 프로젝트입니다.

- MediaPipe / PyTorch 기반 낙상 탐지
- Django 백엔드 및 실시간 알림 기능 구현
- 프로젝트 관리 및 협업 경험 수행
