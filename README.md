## 🚀 Projects

### 1. 낙상 감지 시스템 프로젝트
실시간 낙상 감지를 목표로  
포즈 추정, 딥러닝 모델, 웹 연동을 결합한 프로젝트입니다.

- MediaPipe / PyTorch 기반 낙상 탐지
- Django 백엔드 및 실시간 알림 기능 구현
- 프로젝트 관리 및 협업 경험 수행
  
### 2. iM뱅크 중소기업 세분화 프로젝트
기존 안정성 중심 기업등급을 보완하기 위해  
**활동성(FAI)** 과 **수익성(FPI)** 을 결합한 중소기업 세분화 모델을 설계한 프로젝트입니다.

- 중소기업 고객을 4개 세그먼트로 분류
- 비모수 통계검정 기반 가설 검증 수행
- 숨은 우량 고객군 및 잠재 우량고객 발굴

### 3. Hidden VIP Finder 프로젝트

법인 고객 거래 데이터를 활용해 고객 등급을 예측하고,
최우수 고객과 유사한 패턴을 보이는 잠재 우량 고객 Hidden VIP를 발굴한 프로젝트입니다.

- 347,299건의 법인 고객 거래 데이터 기반 3-class 등급 예측
- PyCaret AutoML 및 트리 기반 모델을 활용한 고객 등급 분류
- SHAP 기반 업종별 핵심 성장 요인 해석
- Hidden VIP 발굴, NBA 추천, 전담 배정 우선순위 도출

### 4. FinMate 금융 문서 검색 AI 프로젝트

금융 문서를 업로드하면 OCR·PDF 파싱을 통해 텍스트를 추출하고,
RAG 기반으로 문서 내용을 검색·질의응답할 수 있는 금융 문서 AI Agent를 개발한 프로젝트입니다.

- PDF/이미지 금융 문서 업로드 및 파싱 자동화
- 청킹·임베딩 후 Chroma Vector DB 저장
- MySQL을 활용한 문서 메타데이터, 채팅 기록, 검색 근거 관리
- Gemini Embedding 및 LLM을 활용한 근거 기반 답변 생성
- FastAPI 기반 백엔드 API와 웹 UI 연동
